# Amit Kumar — Portfolio

Source for my personal software engineer portfolio, live at:
**https://amitkumar55555.github.io/Portfolio/**

## About

A single-page portfolio showcasing my projects — a staff shift-scheduling
app built for a real small business, a real-time Berlin weather app, and a
couple of smaller fundamentals projects — built from scratch with plain
HTML, CSS, and JavaScript. No frameworks, no build tooling, no dependencies.

## Structure

- `index.html` — page markup and content
- `style.css` — styling (a dark, typewriter/terminal-inspired theme)
- `script.js` — the typing animation used in the hero section
- `amit-photo-bw.jpg` — profile photo
- `roster-*.png` / `roster-*.gif` — screenshots for the featured project

## Running Locally

Clone this repository and open `index.html` directly in a browser — no
dependencies or build step required.
